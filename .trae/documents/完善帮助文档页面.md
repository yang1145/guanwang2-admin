# 完善帮助文档页面

## Context
首页右侧栏原有"帮助文档"区域，包含3个静态链接（如何发布新产品、如何管理用户权限、系统配置说明），但点击后无实际跳转。用户希望创建一个完整的帮助文档页面，作为系统各功能模块的使用手册。

## 实施步骤

### 1. 创建帮助文档页面组件
**文件**: `src/views/HelpDocs.vue`

采用左右布局：
- **左侧**：目录导航（使用 `el-menu`），按功能模块分类
- **右侧**：文档内容区，根据左侧选择切换显示

文档分类及内容：
1. **产品管理** — 添加/编辑/删除产品、产品图片上传、产品分类
2. **商品管理** — 商品上架、价格设置、库存管理
3. **新闻发布** — 发布新闻、编辑/删除新闻、新闻分类
4. **用户管理** — 添加用户、角色权限、禁用/启用账号
5. **留言管理** — 查看留言、回复/标记、批量操作
6. **分类管理** — 创建分类、层级结构、排序调整
7. **网站设置** — 基础配置、SEO设置、联系方式、Logo上传

每个分类使用 `el-collapse` 或分段展示操作步骤，配合 Element Plus 的图标和标签保持风格一致。

### 2. 注册路由
**文件**: `src/router/index.js`

- 导入 `HelpDocs` 组件
- 在 `/admin` children 中添加 `{ path: 'help', name: 'HelpDocs', component: HelpDocs }`

### 3. 添加侧边栏菜单项
**文件**: `src/components/SidebarMenu.vue`

- 在"系统管理"子菜单下添加 `<el-menu-item index="help">帮助文档</el-menu-item>`
- 在 `handleSelect` 的 switch 中添加 `case 'help': router.push('/admin/help'); break;`
- 在 `routeMap` 中添加 `'/admin/help': 'help'`

### 4. 更新首页帮助链接
**文件**: `src/views/Home.vue`

- 将3个静态 `<a href="#">` 链接替换为可点击跳转到 `/admin/help` 的链接
- 每个链接携带不同的锚点参数，直接定位到对应文档章节

## 验证方式
1. 启动前端开发服务器，登录后访问 `/admin/help`
2. 确认侧边栏菜单"帮助文档"可正常点击跳转
3. 确认首页帮助链接可跳转到对应章节
4. 确认文档内容完整、排版美观
