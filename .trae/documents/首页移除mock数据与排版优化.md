# 首页移除 mock 数据与排版优化

## Context
当前首页存在多处 mock/硬编码数据：天气问候语、待办事项、本周访问、统计卡片初始值、最新动态。这些数据不反映真实系统状态，且最新动态区域占用较大空间。本次改造将移除所有 mock 数据，改用后端 API 提供的数据，并重新优化首页排版。

## 实施步骤

### 1. 改造顶部欢迎区
**文件**: `src/views/Home.vue`

- 移除固定的天气问候和待办/本周访问统计
- 改为展示真实登录信息、当前日期和一句动态欢迎语
- 保留简洁的页面标题风格

### 2. 统计卡片数据真实化
**文件**: `src/views/Home.vue`

- 保留 4 张统计卡片：用户数、产品数、新闻数、留言数
- 访问量暂时由前端累计或隐藏（后端暂无访问量 API）
- 通过 `loadData` 并行请求：
  - `getUserCount()` — 用户数
  - `getProducts()` — 产品数
  - `getNews()` — 新闻数
  - `getContactMessages()` — 留言数
- 增加加载状态 `loading`，卡片显示骨架屏或 loading 效果

### 3. 移除最新动态模块
**文件**: `src/views/Home.vue`

- 删除"最新动态" el-card 及其相关 CSS
- 移除 `activities` 响应式变量

### 4. 新增快捷入口与待办提醒区
**文件**: `src/views/Home.vue`

- 在统计卡片下方新增两行内容：
  - 左侧：快捷导航网格（保留并优化现有 6 个入口）
  - 右侧：系统待办提醒卡片（基于真实数据：未处理留言数、未读新闻/产品数等）
- 待办数据从已有 API 计算：未处理留言 = `contacts` 中 status 为未处理的记录数

### 5. 右侧栏调整
**文件**: `src/views/Home.vue`

- 保留"帮助文档"卡片，更新链接为 HelpDocs 页面锚点
- 保留"版本信息"卡片
- 可新增"系统状态"小卡片，展示前端版本和 API 连接状态

### 6. 排版优化
**文件**: `src/views/Home.vue` 的 `<style>` 部分

- 统一卡片间距、标题样式
- 统计卡片增加图标背景和悬停动效
- 快捷入口优化为更紧凑的网格布局
- 响应式适配移动端

## 关键修改文件
- `src/views/Home.vue`：主要改造文件
- `src/api/contact.js`：复用现有 API，无需修改

## 验证方式
1. 启动前端 dev server，登录进入首页
2. 观察统计卡片是否显示真实数据（用户数、产品数、新闻数、留言数）
3. 确认"最新动态"已消失，页面布局更紧凑
4. 检查快捷入口和待办提醒正常显示
5. 移动端下验证响应式布局
